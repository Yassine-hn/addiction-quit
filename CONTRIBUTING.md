# Contributing

Thanks for your interest in contributing to Addiction Quit. By participating, you agree to follow this project's code of conduct.

How to contribute:

- Fork the repository and create feature branches.
- Open a Pull Request with a clear description of changes.
- Ensure code follows existing style and run `flutter analyze`.
- Add tests for new logic where appropriate.

Reporting issues:

- Open issues with reproducible steps, expected vs actual behavior, and environment details.

Local development:

```bash
flutter pub get
flutter analyze
flutter test
```

Thank you for helping improve the project!
